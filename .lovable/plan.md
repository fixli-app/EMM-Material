# Bulk Combination Analysis → Excel for Technical Validation

## Goal
Produce one Excel workbook that lists **every possible combination** of Material × Application × Industry × Challenge, with the computed match score, so the technical team can check whether the tool's recommendations and rankings are correct against the datasheets.

The scores are generated by faithfully re-implementing the exact algorithm used in `SmartSelector.tsx` — no new logic, no guessing. The Excel becomes a transparent audit of what the live tool does.

## What the data contains today
- **17 materials** — 12 coated Somaloy grades (1P / 3P / 5P) + 5 uncoated iron/alloy grades.
- **9 applications** (Traction Motors, AC Compressors, Pumps, DC/DC Converters, Industrial Drives, Ventilation Fans, Solar/Renewables, Inductors & Transformers, Sensors & Solenoids).
- **4 industries** (Automotive & EV, Industrial, Energy & Renewables, Electronics & Power).
- **11 challenge scenarios** spread across the applications (e.g. Axial flux, High thermal load, High switching frequency, Cost-optimized…).
- **11 scored properties** (permeability, core loss low/high, Bsat, resistivity, TRS, compressibility, density, thermal, cost, sustainability), each 0–100 normalized from datasheets.

## Scoring logic that will be reproduced exactly
1. Each application activates its `requiredProperties`, each set to weight ≥ 70.
2. A selected challenge adds `propertyBoosts` on top (capped at 100).
3. Score = weighted average: `Σ(propertyValue × weight) / Σ(weight)`.
4. **+5 bonus** if the material is in the application's `recommendedMaterials`.
5. Final score rounded, capped at 100.
6. Industry acts only as an **availability filter** (does the material serve that industry) — it does not change the score.

## Excel workbook structure
The file will be written to `/mnt/documents` and offered for download.

**Sheet 1 — Full Combination Matrix** (the core deliverable)
One row per Application × Industry × Challenge (incl. a "No specific challenge" baseline) × Material:
| Industry | Application | Challenge | Material | Series (1P/3P/5P/Iron) | Score | Rank within combo | Recommended? | Serves this industry? | Datasheet flags (μmax, Bsat, core loss) |

Rows sorted by Application → Challenge → Score. Recommended grades highlighted. This is the sheet the team scans to confirm "for this app/challenge, is the top-scoring / recommended material the right one?"

**Sheet 2 — Recommendation vs Algorithm Check**
Per Application (and per challenge): the officially `recommendedMaterials` list vs the algorithm's top 5 by score, side by side, flagging any mismatch — the fastest way for experts to spot disagreements.

**Sheet 3 — Materials Reference**
All 17 materials with raw datasheet specifications AND the 0–100 normalized property scores, so the team can verify the normalization behind every score.

**Sheet 4 — Applications Reference**
Each application's required properties, the resulting weights, its industries, and its challenge scenarios with exact property boosts.

**Sheet 5 — Methodology**
Plain-language description of the formula, the +5 bonus, the industry filter, and the datasheet source note — so reviewers understand exactly how each number was produced.

## Combination volume
9 applications × their industries × (challenges + baseline) × 17 materials ≈ several thousand rows — complete and exhaustive, but generated programmatically so it stays consistent with the code.

## Technical approach
- Parse `src/data/materials.ts` structures and re-implement the `scoredMaterials` computation from `SmartSelector.tsx` in a generation script (openpyxl), guaranteeing the Excel matches the live tool.
- Apply light formatting (bold headers, frozen header row, recommended-row highlight, conditional color scale on Score) consistent with Höganäs' clean corporate style.
- QA every sheet by rendering to images and checking for overflow/errors before delivering.

## Deliverable
A single `.xlsx` (e.g. `hoganas-material-combination-analysis.xlsx`) in `/mnt/documents`, ready to hand to the technical team, plus a short summary of any recommendation-vs-algorithm mismatches found during generation.

No changes to the app itself — this is a standalone export.
